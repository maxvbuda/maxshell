## How computers work
aka: computer, what is a computer
A computer is a machine that follows instructions to process information. Its main parts are the CPU (processor), which carries out instructions; memory (RAM), which holds what’s being worked on; storage (an SSD or hard drive), which keeps files when the power is off; and input and output devices like the keyboard and screen.

Deep down, everything is stored as binary — ones and zeros — represented by billions of tiny switches called transistors. Programs are lists of instructions, written by people in programming languages and translated into the machine’s own code.
Q: What is the difference between RAM and storage? | RAM is fast, temporary memory for what’s running now; storage (SSD or hard drive) keeps files permanently.

## The CPU
aka: cpu, processor, what does a processor do
The CPU (central processing unit) is the computer’s brain. It fetches instructions from memory, decodes them and executes them, billions of times a second. Its speed is measured in gigahertz (GHz), and modern CPUs have several cores, each able to work on something at the same time.

Graphics cards contain GPUs, which have thousands of smaller cores that are great at doing lots of simple calculations at once — perfect for games, video and training AI models.
Q: What is a GPU? | A graphics processing unit: a chip with thousands of small cores that do many calculations in parallel, used for graphics, games and AI.

## Binary
aka: binary numbers, bits and bytes
Computers store everything as binary: numbers written with only 0 and 1. Each digit is a bit, and 8 bits make a byte, which can hold 256 different values — enough for one letter of text. In binary, 1 is 1, 2 is 10, 3 is 11, 4 is 100 and so on: each place is worth double the one to its right.

A kilobyte is about a thousand bytes, a megabyte about a million, a gigabyte about a billion, and a terabyte about a trillion.
Q: How many bits are in a byte? | Eight.
Q: What is 5 in binary? | 101 — that’s 4 + 0 + 1.

## Programming
aka: what is programming, coding, what is code
Programming (coding) is writing instructions for a computer in a programming language. A program can be as small as a line that prints “Hello” or as big as a web browser or a game. Programmers break problems into steps, use variables to store data, conditions to make decisions, loops to repeat things, and functions to organise code.

Popular languages include Python (friendly and versatile), JavaScript (the language of the web), Java, C and C++ (fast, used for systems and games), Swift (Apple apps) and many more. The best way to learn is to build small projects and fix the bugs you hit along the way.
Q: What is the best programming language for beginners? | Python is a great first choice: it’s readable and used everywhere. JavaScript is great if you want to make websites.
Q: How long does it take to learn to code? | You can write small programs within weeks; getting really good takes a few years of regular practice.

## The internet
aka: how the internet works
The internet is a worldwide network of networks. When you visit a website, your device sends a request, broken into small packets, through your router and your internet provider, across cables and routers — including undersea cables — to a server, which sends the page back the same way. Every device has an IP address, and the DNS system turns names like example.com into those addresses.

The web, email, video calls and online games all run over the internet.
Q: What is an IP address? | A number that identifies a device on a network, so data knows where to go.
Q: What is DNS? | The internet’s phone book: it turns website names into IP addresses.

## Websites
aka: how websites work, html css javascript
A website is made of files that a browser downloads and displays. HTML gives the page its structure and content (headings, paragraphs, images, links), CSS styles it (colours, fonts, layout), and JavaScript makes it interactive (buttons that do things, forms, games).

The files live on a web server. When you type an address, your browser asks the server for them over HTTP (or HTTPS, which is encrypted). You can build a simple website with nothing but a text editor and a browser.
Q: What is HTML? | HyperText Markup Language — the code that gives web pages their structure and content.
Q: What is CSS? | Cascading Style Sheets — the code that controls how web pages look: colours, fonts and layout.
Q: What is the difference between HTML, CSS and JavaScript? | HTML is the content and structure, CSS is the style, and JavaScript is the behaviour.

## Operating systems
aka: operating system, what is an os
An operating system (OS) is the software that runs the computer and lets other programs work. It manages memory, files, devices and running programs, and provides the desktop or home screen you use. Examples: macOS, Windows and Linux on computers; iOS and Android on phones.

The terminal (or command line) lets you control the OS by typing commands, which is powerful for programmers and automating tasks.

## Artificial intelligence
aka: ai, what is ai, machine learning
Artificial intelligence (AI) is software that can do tasks we associate with intelligence, like understanding language, recognising images or playing games. Most modern AI uses machine learning: instead of being given every rule, a model learns patterns from lots of examples.

Neural networks are machine-learning models made of layers of simple connected units, loosely inspired by the brain. Language models, like me, are trained to predict the next word in text; by doing that on a lot of text, they learn to answer questions and write. AI can be very useful but also makes mistakes, so it’s wise to double-check important answers.
Q: What is machine learning? | A way of making software learn patterns from examples instead of following hand-written rules.
Q: What is a neural network? | A model made of layers of simple connected units with adjustable weights, which learns by adjusting those weights from examples.
Q: How do language models work? | They are trained to predict the next word (token) in text; after seeing lots of text, they can answer questions and write.

## Cybersecurity
aka: staying safe online, online safety, passwords
Staying safe online comes down to a few habits: use long, unique passwords (a password manager helps), turn on two-factor authentication, keep your software updated, and be suspicious of unexpected messages asking you to click a link or give personal details — that’s phishing.

Only download apps from trusted places, don’t share passwords, and think before posting personal information. If something seems too good to be true, it probably is.
Q: What is phishing? | A scam where someone pretends to be a trusted company or person to trick you into giving passwords or personal details.
Q: What is two-factor authentication? | A second check, like a code on your phone, on top of your password, so a stolen password isn’t enough.

## Git and version control
aka: version control, what is git, github
Version control keeps the history of your files, so you can see what changed, go back to earlier versions and work with other people without overwriting each other’s work. Git is the most popular version control system: you save snapshots called commits, and work on separate lines of changes called branches.

GitHub is a website that hosts Git repositories online, making it easy to share code, review changes (pull requests) and collaborate.
Q: What is the difference between git and github? | Git is the version control tool on your computer; GitHub is a website that hosts Git repositories and adds collaboration features.

## Algorithms
aka: algorithm, what is an algorithm
An algorithm is a step-by-step set of instructions for solving a problem, like a recipe. Computers run algorithms for everything: sorting a list, finding the shortest route on a map, recommending videos. Good algorithms solve problems correctly and efficiently.

Classic examples include binary search (finding something in a sorted list by repeatedly halving it), sorting algorithms like merge sort and quicksort, and graph algorithms for finding shortest paths.

## Databases
aka: database, sql
A database is an organised store of data that programs can search and update quickly. Relational databases, like PostgreSQL, MySQL and SQLite, keep data in tables with rows and columns and use SQL (Structured Query Language) to query it — for example `SELECT name FROM users WHERE age > 18`.

Other kinds (“NoSQL” databases) store documents, key-value pairs or graphs. Almost every app — from banking to social media — is built on a database.
Q: What does SQL stand for? | Structured Query Language.
